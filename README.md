## 📝 Format Dokumentasi

Setiap modul menggunakan format dokumentasi yang relatif konsisten agar seluruh laporan mudah dibaca dan dipelajari.

### Struktur laporan

```text
README.md
│
├── A. Tujuan
├── B. Dasar Teori
├── C. Praktikum
│   ├── Langkah 1
│   ├── Langkah 2
│   ├── Langkah 3
│   └── ...
└── D. Kesimpulan
```

Untuk setiap langkah praktik, dokumentasi dapat dilengkapi dengan:

* Penjelasan langkah
* Perintah atau source code
* Screenshot hasil praktik
* Penjelasan hasil
* Kesimpulan

Contoh pemanggilan screenshot:

```html
<img src="images/01_Download_Git.png" width="700">
```

Dengan cara tersebut, screenshot dapat ditampilkan langsung pada halaman GitHub.

## 🌱 Branch dan Kolaborasi
Repository ini juga menjadi sarana untuk memahami workflow kolaborasi menggunakan Git dan GitHub.

Alur kolaborasi:

```text
Repository
     │
     ├── main
     │
     └── branch pengembangan
              │
              ↓
           Commit
              │
              ↓
            Push
              │
              ↓
       Pull Request
              │
              ↓
           Review
              │
              ↓
            Merge
```

Konsep tersebut digunakan untuk memahami bagaimana perubahan dapat dikelola secara terstruktur tanpa langsung mengubah branch utama.
